## Apa Ini?

Convention guide ini mendefinisikan cara terstruktur untuk membangun aplikasi Next.js 15+ dengan App Router.
Tujuannya satu: **setiap developer (dan AI) bisa langsung paham kode tanpa penjelasan tambahan**.

<CardGrid>
  <Card title="Folder Structure" icon="seti:folder">
    Di mana meletakkan setiap jenis file — feature folder, `$action`, `$element`, `$function`, `$store`, `$lib`.
  </Card>
  <Card title="Naming Conventions" icon="pencil">
    Prefix konsisten untuk semua simbol: `ACT_`, `SE_`, `CE_`, `SFN_`, `CFN_`, `APIS_`, `APIC_`, `ZS_`.
  </Card>
  <Card title="Pattern Guide" icon="open-book">
    9 pattern data flow dari server ke client — Server Fetch, Form Submit, URL Params, Zustand, i18n, dan lainnya.
  </Card>
  <Card title="Example Use Case" icon="rocket">
    Contoh implementasi pattern data flow dari server ke client.
  </Card>
</CardGrid>

</ContainerSection>

## Stack yang Diasumsikan

```
Next.js 15+  (App Router)
├── UI            shadcn/ui
├── State         Zustand (transient) | nuqs (URL Search Params)
├── Server State  TanStack Query
├── Forms         TanStack Form + Zod
├── i18n          next-intl
└── Language      TypeScript strict
```

</ContainerSection>

<ContainerSection>

## 9 Pattern Data Flow

Setiap fitur dibangun menggunakan satu atau lebih dari pattern berikut:

<CardGrid>
  <Card title="A — Server Fetch" icon="server">
    Data dibutuhkan saat halaman pertama render.
  </Card>
  <Card title="B — Client Fetch" icon="window">
    Data perlu di-refresh atau polling via TanStack Query.
  </Card>
  <Card title="C — Form Submit" icon="seti:default">
    Semua form — create, update, delete via Server Action.
  </Card>
  <Card title="D — URL Search Params" icon="seti:code-search">
    Search, filter, pagination yang bisa di-bookmark via nuqs.
  </Card>
  <Card title="E — Zustand Store" icon="setting">
    Modal, selection, toggle — state yang tidak perlu di URL.
  </Card>
  <Card title="F — shadcn/ui Extension" icon="puzzle">
    Semua komponen UI berbasis shadcn — wrapper, tidak modifikasi langsung.
  </Card>
  <Card title="G — Library Adapter" icon="seti:pipeline">
    Integrasi Redis, S3, email, dan third-party library lainnya.
  </Card>
  <Card title="H — i18n" icon="translate">
    Semua teks user-facing via next-intl.
  </Card>
  <Card title="I — API Mocking" icon="seti:bicep">
    Testing dan development dengan MSW.
  </Card>
</CardGrid>
