## Apa Ini?

Convention guide ini mendefinisikan cara terstruktur untuk membangun aplikasi Next.js 15+ dengan App Router.
Tujuannya satu: **setiap developer (dan AI) bisa langsung paham kode tanpa penjelasan tambahan**.

Convention ini mencakup tiga area:

| Area | Isi |
|------|-----|
| **Folder Structure** | Di mana meletakkan setiap jenis file |
| **Naming Conventions** | Prefix dan pattern untuk semua simbol |
| **Pattern Guide** | Cara data mengalir dari server ke client |

---

## Stack yang Diasumsikan

```
Next.js 15+  (App Router)
├── UI            shadcn/ui
├── State         Zustand (transient) | nuqs (URL Search Params)
├── Server State  TanStack Query
├── Forms         TanStack Form + Zod
├── i18n          next-intl
└── Language      TypeScript strict
```

---

## 8 Pattern Data Flow

Setiap fitur dibangun menggunakan satu atau lebih dari 8 pattern berikut:

| Pattern | Nama | Kapan Dipakai |
|---------|------|---------------|
| A | Server Fetch | Data dibutuhkan saat halaman pertama render |
| B | Client Fetch (TanStack Query) | Data perlu di-refresh atau polling |
| C | Form Submit | Semua form — create, update, delete |
| D | URL Search Params (nuqs) | Search, filter, pagination yang bisa di-bookmark |
| E | Zustand | Modal, selection, toggle — state yang tidak perlu di URL |
| F | shadcn/ui Extension | Semua komponen UI berbasis shadcn |
| G | Library Adapter | Integrasi Redis, S3, email, dll. |
| H | i18n dengan next-intl | Semua teks yang tampil ke user |
